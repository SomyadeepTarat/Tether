# Presenting the workflow

The general-request project is a single reviewed response. It completes after approval.
Use a new cloud-comparison project to demonstrate multiple milestones and specialists.

1. Expand **Presenting Tether? Open the workflow demo guide** above the dashboard.
2. Click **Set up four-milestone demo**. The form is prefilled with the supported goal
   and **Research + Report** selected. Create it when ready to make model calls.
3. Expand **Approved contract v1** to show the goal, approved topics, hard constraints,
   and JSON. Research and Report receive the same approved contract. Their outputs
   go through separate deterministic checks.
4. Show the milestone list: costs, deployment, comparison, recommendation. Execution
   progress expands while running. Exact quotations may commit automatically;
   comparison and recommendation require review. Review one, explain approval, and
   show progression to the next. Inference can still fail or require attention;
   live model results are not guaranteed.
5. Open the research handoffs to show accepted findings passed from Research to Report.
   These are sequential specialist calls, not concurrent independent agents.
6. In the guide, click **Show ALLOW / REVIEW / BLOCK** to demonstrate all three safety
   decisions reliably without model calls. Expand each scripted proposal and read
   the real validator's reasons. This rehearsal uses a separate sample contract;
   it does not add actions to the selected project's history or change its milestones.
7. Optional: request **Add serverless comparison** and approve the scope change to
   show immutable contract v2 and an additional milestone. This is separate from
   approving a report proposal. Resume the workflow to perform the new work.

The safety rehearsal is explicitly scripted. It is not evidence that a live model
produced the example or that an agent executed it. Existing projects are preserved.
